## Windows 试装 · v0.4.0 RC1

- [下载 Windows 安装 ZIP](https://github.com/henry-tinker-ai/workplace-dialogue-lab/releases/download/v0.4.0-rc1/workplace-dialogue-lab-v0.4.0-rc1.zip)
- [下载 SHA-256 校验文件](https://github.com/henry-tinker-ai/workplace-dialogue-lab/releases/download/v0.4.0-rc1/workplace-dialogue-lab-v0.4.0-rc1.zip.sha256)
- [查看预发行说明](https://github.com/henry-tinker-ai/workplace-dialogue-lab/releases/tag/v0.4.0-rc1)

登录有此私有仓库访问权限的 GitHub 账号后下载 ZIP。解压并双击 `install-windows.cmd`，需安装 WorkBuddy 和 Python 3.9 或更新版本。
